Binary Search — Kth Missing Positive
======================================

Problem: [LeetCode 1539 — Kth Missing Positive Number](https://leetcode.com/problems/kth-missing-positive-number/)

## Recognize the boundary

The array is strictly increasing and contains positive integers. At index i, the count of positive integers missing before arr[i] is:

    missing(i) = arr[i] - (i + 1)

This count never decreases as i moves right. So binary-search the first index where missing(i) >= k. That is the first position at which at least k values have already been skipped.

## Java solution

```java
class Solution {
    public int findKthPositive(int[] arr, int k) {
        int lo = 0, hi = arr.length;

        // Find the first index with at least k missing values before it.
        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;
            int missing = arr[mid] - (mid + 1);

            if (missing >= k) {
                hi = mid;
            } else {
                lo = mid + 1;
            }
        }

        // lo array values plus k missing values place the answer here.
        return lo + k;
    }
}
```

The search uses a half-open range [lo, hi). When the condition is true, keep mid as a possible boundary with hi = mid. Otherwise, discard mid and everything before it with lo = mid + 1.

## Dry run

For arr = [2, 3, 4, 7, 11] and k = 5:

| i | arr[i] | Missing before arr[i] |
|---:|---:|---:|
| 0 | 2 | 1 |
| 1 | 3 | 1 |
| 2 | 4 | 1 |
| 3 | 7 | 3 |
| 4 | 11 | 6 |

The first index with at least 5 missing values is 4. Therefore the answer is lo + k = 4 + 5 = 9. The missing positives are 1, 5, 6, 8, 9.

## Quick checks

| arr | k | Expected |
|---|---:|---:|
| [2, 3, 4, 7, 11] | 5 | 9 |
| [2, 3, 4, 7, 11] | 1 | 1 |
| [1, 2, 3, 4] | 2 | 6 |
| [5, 6, 7] | 2 | 2 |
| [1] | 1 | 2 |

## Why return lo + k?

At the boundary, lo array values occur before the answer, and k missing positive values must also occur before or at it. Together they place the kth missing value at position/value lo + k. This also handles both ends:

- If the first missing values occur before arr[0], the boundary is 0 and the answer is k.
- If fewer than k values are missing within the array, the boundary is arr.length and the answer is arr.length + k.

## Common mistakes

- Searching for equality with k. The missing-count function may skip over k, so search for the first count >= k.
- Returning arr[lo] at the boundary. The answer can be absent from the array.
- Using a closed interval but applying half-open updates. Here hi starts at arr.length and the loop condition is lo < hi.
- Forgetting that zero-based index i corresponds to i + 1 positive array values.

Time: O(log n). Extra space: O(1).
